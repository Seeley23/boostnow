## 🔧 KROK 3: Troubleshooting (Jeśli Potrzebne)

### Jeśli Mniej Niż 40 Stron Indeksowanych

**Diagnoza:**
- [ ] Sprawdź Coverage - czy są błędy?
- [ ] Sprawdź Sitemaps - czy sitemap jest dostępny?
- [ ] Sprawdź robots.txt - czy pozwala na crawling?

**Akcje:**
- [ ] Czekaj kolejne 7 dni (Google indeksuje stopniowo)
- [ ] Dodaj backlinki (zwiększ crawl budget)
- [ ] Sprawdź Page Speed (może serwer jest wolny)
- [ ] Prześlij sitemap ponownie

### Jeśli 0 Impressions Po 7 Dniach

**Diagnoza:**
- [ ] Sprawdź, czy strona jest indeksowana: `site:boostnow.pl` w Google
- [ ] Sprawdź Coverage - czy wszystkie strony są "Valid"?

**Akcje:**
- [ ] Czekaj kolejne 7 dni (Google czasami czeka dłużej)
- [ ] Dodaj backlinki z wysokiej autorytetu stron
- [ ] Sprawdź, czy strona jest dostępna (nie ma 404)
- [ ] Sprawdź, czy meta tags są prawidłowe

### Jeśli Niska Pozycja (40+) dla Głównych Keywords

**Diagnoza:**
- [ ] Sprawdź title/description - czy są optymalne?
- [ ] Sprawdź H1/H2 headings - czy zawierają keywords?
- [ ] Sprawdź content - czy jest wystarczająco długi?

**Akcje:**
- [ ] Popraw on-page SEO (title, description, H1, H2)
- [ ] Dodaj backlinki z wysokiej autorytetu stron
- [ ] Zwiększ dwell time (lepszy content, UX)
- [ ] Czekaj - nowe strony potrzebują czasu

### Jeśli Błędy w Coverage

**Diagnoza:**
- [ ] Kliknij na błędy w Coverage
- [ ] Sprawdź "Inspect URL" dla każdego błędu
- [ ] Przeczytaj szczegóły błędu

**Akcje:**
- [ ] Napraw problem (zwykle meta tags, canonical, noindex)
- [ ] Prześlij sitemap ponownie
- [ ] Czekaj na re-crawl (Google spróbuje ponownie)
